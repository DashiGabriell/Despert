Design System Meritum · 3D

Variáveis plástico

Definidas em tokens-3d.css. Sem drop-shadow / glow externo. Volume só com inset + gradiente.

Variável Uso
--shadow / --glow-*none (sombra/glow externo zero)
--plastic-raisedRelevo do botão (inset claro/escuro)
--plastic-pressedEstado pressionado (afundado)
--plastic-raised-lightSecondary / outline / ghost
--plastic-pressed-lightPress desses botões claros
--btn-3d-*Gradientes plastificados
--depth-yDeslocamento no clique
data-state="clicked"Press animado via JS (~180ms)
